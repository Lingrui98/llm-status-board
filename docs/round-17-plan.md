## 1. 版位与折叠语义

- **行序**：`summary-bar` → `global-stats` → `card-grid` → **洞察** → **深度分析**（两区块在所有账号卡片之后，顺序不变：洞察在前）。
- **默认收起**：两区块 `open` 初值来自 localStorage，**无记录时为 `false`（收起）**。
- **记住的是「用户选择」**：键 `lsb-bottom-sections`，值为 `{"insights":boolean,"analysis":boolean}`；只在用户点击头部时写入；不得把「默认收起」当成用户选择写盘（判别方法：全新用户点开洞察后重载 → 洞察展开、分析仍收起）。
- **折叠态一行摘要（必须有，收起也要有信息量）**：
  - 洞察：`N 条未读提醒 · 最紧急：<账号> <原因>`（无提醒 → `暂无未读提醒`）。
  - 深度分析：`近 7 天花费 $X · 环比 ±Y%`（无数据 → `暂无本地用量数据`）。
  - 摘要与展开内容**必须同源**（同一 `useMemo` 结果），不允许折叠态另算一套。
- **切换**：点击区块头任意位置切换；保留 `aria-expanded`，新增 `aria-controls` 指向内容容器 id；键盘 Enter/Space 可切换、焦点环可见；内容容器用 `hidden` 或条件渲染，收起时不进入 Tab 序。
- **空态**：收起态与展开态都要给可执行提示（如「去设置里添加账号」按钮，复用现有 `onGoSettings`），不得只显示「暂无数据」。

## 2. 观感重做验收方向（验收依据，不写实现细节）

1. **统一区块头语言**：洞察/深度分析/全局统计使用同一套头部结构（标题 + 折叠按钮 + 右侧操作），与 `.global-stats-head` 同族；标题改人类可读命名（如「洞察」「深度分析」，不带 R14/R15 代号）。
2. **数字优先、图表其次**：每区块首屏先给 1–3 个关键数字（大字号），图表/列表退居其后。
3. **减边框与阴影叠加**：一个区块至多一层边框 + 至多一个阴影；不用「卡片套卡片」。
4. **图表降噪**：网格线只保留水平方向、坐标轴去掉多余刻度与边框、同屏色相 ≤3 种、图例可省则省（信息进标题/摘要）。
5. **空态可执行**：见 §1 末条。
6. **明暗两套**：颜色一律走现有主题变量，禁新增硬编码色值；关键文本对比度 ≥ 4.5:1。
7. **reduced-motion**：`@media (prefers-reduced-motion: reduce)` 下取消过渡与动画（含折叠展开）。
8. **键盘与焦点**：所有交互元素可 Tab 到达、焦点环样式统一可见、折叠按钮有可读无障碍名。
9. **不动数据口径**：只改呈现，不改任何计算/阈值/排序。

## 3. 托盘左键精确行为

- 判定顺序（`MouseButton::Left` + `ButtonState::Up` 时）：**`is_visible() == true` 且 `is_minimized() == false` → `hide()`**；否则 → `show()` + `unminimize()` + `set_focus()`。
- **最小化边界**：窗口可见但被最小化 → 还原并聚焦（**不**隐藏），符合「点击托盘要看界面」的直觉。
- **与「✕ 隐藏到托盘」开关解耦**：本行为不读也不改 `closeToTray`；关闭该开关时左键切换依然生效。
- **菜单「显示看板」保持只显示不隐藏**（不做 toggle），`MENU_SHOW` 语义不变。
- **平台一致**：Windows 与 macOS 走同一份 Rust 逻辑（`is_visible`/`is_minimized` 语义一致）；失败一律 `let _ =` 静默降级，不得 panic。
- 左键**不**触发刷新、**不**改变暂停态、**不**改 tooltip；`show_menu_on_left_click(false)` 保持。

## 4. AC 清单（可判定；每条指向 §）

- AC-1 行序（§1）：主分支 DOM 中 `card-grid` **之后**才出现洞察、深度分析（`compareDocumentPosition` 断言），且二者顺序为洞察→分析。
- AC-2 首次收起（§1）：清空 `lsb-bottom-sections` → 两区块 `aria-expanded="false"`，内容容器 `hidden`/未挂载。
- AC-3 记住展开（§1）：仅展开洞察 → 重载后洞察展开、**分析仍收起**（证明记住的是单项选择而非「有记录就全展开」）。
- AC-4 记住收起（§1）：展开后手动收起分析 → 重载后分析收起。
- AC-5 摘要同源（§1）：折叠态摘要中的数值与展开后同一数据一致（洞察未读数 = 展开后的未读条目数；分析 7 天花费 = 展开后周期对比的当期花费）。
- AC-6 折叠 a11y（§1/§2）：折叠按钮具备 `aria-expanded` + `aria-controls`，Enter/Space 可切换，收起时内容不进入 Tab 序。
- AC-7 左键隐藏（§3）：`is_visible()=true` 且未最小化 → 左键后 `is_visible()=false`。
- AC-8 左键显示聚焦（§3）：`is_visible()=false` → 左键后可见且聚焦（`is_focused()`）。
- AC-9 最小化还原（§3）：`is_minimized()=true` → 左键后可见、未最小化、聚焦。
- AC-10 菜单不回归（§3）：窗口可见时菜单项「显示看板」点击后窗口仍可见（不 toggle）。
- AC-11 观感方向可核（§2）：两区块头部与全局统计同族（同类名/同结构）；每区块首屏存在 ≥1 个大字号关键数字；单区块边框 ≤1 层；图表网格仅水平、同屏色相 ≤3。
- AC-12 明暗/动效/对比度（§2）：明暗两主题下均无硬编码新色值（色值全部来自变量）；`prefers-reduced-motion: reduce` 下折叠无过渡；关键文本对比度 ≥ 4.5:1。
- AC-13 无回归（§2）：既有 329 条用例全绿；R14/R15/R16 的 AC 口径不变；主入口 chunk 仍不含 `recharts-` 源码串。

# R18 托盘悬停「用量总结」浮层 — 执行规格

## 0. 现状与既定裁决（照此实现，勿另起方案）

- **自绘无边框浮层窗口**（label `summary`，HTML/CSS，与主界面同一套设计语言）；**不用原生 `popup_menu`**（样式不可控）。
- 事件源：`tray-icon 0.25.1` 的 `TrayIconEvent::{Enter, Leave, Move}` 均带 `position: PhysicalPosition<f64>` 与 `rect`（托盘图标矩形）；tauri `2.12.2`。
- **不引 recharts**（悬停要秒开）：浮层只用 CSS/SVG 与既有设计原语。
- 与既有交互共存：**左键 = 切换主窗口显示/隐藏（R17 不变）**、**右键 = 原生菜单（不变）**；tooltip **保留现有单行摘要**（浮层出现时不改 tooltip，二者不互斥，避免多一处状态）。
- 现状事实：`tauri.conf.json` 仅 `main`（1180×780，center）；`capabilities/default.json` 为 `windows:["main"]`；可用 IPC = `getConfig / getLastResults / getUsageHistory`（浮层**只用这些**，不新增数据源、不触网）；`styles.css` 已有 `tabular-nums` 先例与 `--bg/--border/--text/--accent/--chart-grid` 等变量。

## 1. 显示/隐藏状态机（精确到毫秒）

- `Enter` → **150ms** 后显示（防误触闪烁）；`Leave` → **250ms** 后隐藏（留出指针移入浮层的余量）。
- 浮层内指针进入：前端 `onMouseEnter` 回报 `pointer_in_summary=true` → **取消待执行隐藏**；离开浮层 → 重新起 250ms 隐藏。
- **立即隐藏（延迟 0）**：`Escape`、浮层失焦（blur）、左键点击托盘（R17 切换主窗口时）、点击某账号行之后、主窗口获得焦点。
- 抖动收敛：**同一时刻最多一个待执行定时器**（新 Enter/Leave 先 `cancel` 旧定时器）；已显示时再次 `Enter` 不重置、不重放动画。
- 状态机与定时决策抽成**纯函数**（`nextHoverState(state, event, now) -> {next, delayMs, action}`），便于无 GUI 单测（AC-1..AC-3）。

## 2. 定位规则（纯函数，物理像素进、逻辑像素出）

- 输入：托盘 `rect`、光标 `position`、`scaleFactor`、**光标所在显示器**的 work area（物理像素）。
- 选边：图标中心偏向工作区**下半**（任务栏在下方）→ 浮层置于图标**上方**；偏上半 → 下方；偏左半 → 右侧；偏右半 → 左侧。同侧再按「图标中心 vs 光标」微调，**保证浮层矩形与光标点不相交（不压光标）**。
- 贴边 `GAP = 8` 物理像素；水平（或垂直）方向以图标中心对齐后 clamp 进 work area（两侧各留 8）。
- 若该侧空间不足 → 退到**对面侧**；仍不足 → 在 work area 内 clamp（不越屏）。
- 多显示器：一律以**光标所在显示器**的 work area 为界；`Move` 事件触发重定位（**节流 ≥100ms**）。
- 换算：`logical = physical / scaleFactor`，`set_position` 用 `LogicalPosition`；误差 ≤1 逻辑像素（AC-6）。

## 3. 窗口配置与能力

- `tauri.conf.json` 新增窗口：`label:"summary"`、`width:300, height:360`、`decorations:false`、`transparent:true`（圆角+阴影走 CSS）、`shadow:false`（Windows 上与 transparent 叠加会出现方角底影）、`alwaysOnTop:true`、`skipTaskbar:true`、`resizable:false`、`visible:false`、`focus:false`。
- **不抢焦点**：Tauri 2 无 no-activate 开关 → **明确接受可能抢焦点**，并以「浮层 `blur` → 立即隐藏」+「主窗口获焦 → 隐藏」兜底（这是本轮已知取舍，不算缺陷）。
- 隐藏用 `hide()`、显示用 `show()`（**不销毁**，避免每次悬停重建 WebView）；先显示骨架再填数据，避免空白闪烁。
- capability：`windows` 改为 `["main", "summary"]`，权限维持 `core:default`（浮层不需要 dialog/autostart/notification）。

## 4. 浮层内容规格（数据只用现有 IPC）

- 头部：「用量总结」+ **最后刷新相对时间**（<1min「刚刚」、<60min「N 分钟前」、<48h「N 小时前」、否则日期）。
- 总览三数：监控账号数；正常/异常（异常 0 → 绿色）；**USD 与 CNY 分栏合计（绝不跨币种相加）**。
- 每账号一行：名称 +（余额，币种前缀）或最紧配额窗口百分比 + 状态点（正常/异常/停用）；异常时附原因（截断 **24 字符**）。
- 本地历史：`本地历史 N 天`（`getUsageHistory` 中日期去重计数）；无历史 → 「随刷新自动积累」。
- 行可点 → 显示并聚焦主窗口（复用 `focusRequest` 打开该账号详情）→ **随后隐藏浮层**。
- 三态：加载中（骨架 2 行）、空（未配置账号 → 「尚未添加账号」纯文案，**不放跳转按钮**，避免浮层承担导航语义）、失败（IPC 报错 → 「读取失败，可在主窗口重试」，不崩）。

## 5. 美观可核条款（只判可核，不做口味判断）

1. 颜色**全部来自现有 CSS 变量**（零硬编码色值）；边框 ≤1 层；阴影 ≤1；圆角 10px。
2. 数字一律 `font-variant-numeric: tabular-nums`；字号层级 12/13/15/20；行高紧凑。
3. 明暗两套与主界面同源；入场动画 ≤120ms（透明度 + 2px 位移），`prefers-reduced-motion: reduce` 下**无动画**。
4. 键盘：`Escape` 关闭；Tab 顺序 = 头部 → 账号行（自上而下）；焦点环可见。
5. 关键文本与数字对比度 ≥4.5:1（含异常红）。

## 6. AC 清单（必须分两类）

**(a) 无 GUI 可验（本轮判定依据）**
- AC-1 状态机定时（§1）：Enter 后 149ms 未显示、150ms 显示；Leave 后 249ms 未隐藏、250ms 隐藏。
- AC-2 待执行定时器收敛（§1）：连续 Enter/Leave 抖动后，任一时刻待执行定时器 ≤1（断言 cancel 次数）。
- AC-3 浮层内指针（§1）：Leave 后回报 `pointer_in_summary` → 隐藏被取消；再离开 → 250ms 隐藏。
- AC-4 立即隐藏（§1）：Escape / blur / 左键 / 行点击 → 延迟 0。
- AC-5 定位选边（§2）：任务栏在下方 → 浮层在图标上方；上/左/右同理；**断言浮层矩形与光标点不相交**。
- AC-6 空间不足（§2）：边缘 + 放不下 → 退对面侧；最终矩形完全落在 work area 内（含 8px 边距）。
- AC-7 scale 换算（§2）：`scaleFactor=2` → 逻辑坐标 = 物理/2，位置误差 ≤1 逻辑像素。
- AC-8 多显示器（§2）：光标在第二显示器 → 以第二显示器 work area 为界 clamp。
- AC-9 窗口配置与能力（§3）：summary 字段 = 上述 6 项 + 300×360 + visible:false；capability `windows` 含 `summary`。
- AC-10 三态渲染（§4）：注入空/加载/失败数据 → 分别渲染占位/骨架/错误文案且不抛错。
- AC-11 内容数值（§4）：账号行数 = 启用账号数；异常行显示原因；USD 与 CNY **分栏不相加**（断言两栏数字）。
- AC-12 行点击（§4）：点击账号行 → 显示主窗口 + `focusRequest(accountId)`（mock 断言参数）+ 隐藏浮层。
- AC-13 Escape（§5）：`keydown` Escape → 隐藏，且不触发主窗口逻辑。
- AC-14 美观可核（§5）：零硬编码色值；边框 ≤1；阴影 ≤1；数字用 tabular-nums；reduced-motion 有规则；Escape/Tab 可达；对比度抽样 ≥4.5:1。
- AC-15 无回归（§0）：主窗口/托盘**左键切换**（R17）/右键菜单/tooltip 行为不变；既有 335 用例全绿；主入口与浮层产物**均不含 recharts**。

**(b) 真机手测项（不得算通过，一律标「需真机手测」）**
- M-1 悬停托盘图标 → ~150ms 后浮层出现在图标旁且**不压光标**。
- M-2 指针移入浮层不消失；移出或按 Escape → 250ms 内消失。
- M-3 任务栏位于屏幕下/上/左/右 → 浮层贴正确一侧且不出屏。
- M-4 双显示器：在第二屏任务栏悬停 → 浮层出现在第二屏、不压光标。
- M-5 左键 → 主窗口显示/隐藏切换（R17 行为）且浮层不残留；右键 → 原生菜单正常。
- M-6 视觉与主界面一致、透明/圆角正常、无闪烁与残影。

## 7. 自查与不做

**AC→§**：AC-1/2/3/4→§1；AC-5/6/7/8→§2；AC-9→§3；AC-10/11/12→§4；AC-13/14→§5；AC-15→§0。（b）类 M-1..M-6 对应 §1/§2/§3 的真机面，**本轮不记为通过**。
**数值笔算**：150/250ms 阈值；`GAP=8`；`scaleFactor=2` → 300/2=150 逻辑宽；`Move` 节流 100ms；原因截断 24 字。
**明确不做**：不改主窗口业务逻辑与数据口径；不加新依赖、不引 recharts；不改托盘左键/右键/tooltip 语义；不做浮层内刷新/导航按钮；不做 macOS 专属分支（仅透明/圆角必要适配）；浮层不做多屏记忆与用户自定义尺寸。

## 8. 手工验证清单（用户装包后约 1 分钟照做）

1. 启动应用，托盘图标出现（悬停要能看到图标本身）。
2. **悬停**托盘图标（不要点击）→ 约 0.15 秒后出现「用量总结」浮层，位于图标旁且**光标不被压住**。
3. 指针从图标**移入浮层**并停留 3 秒 → 浮层不消失。
4. 指针移出浮层 → 约 0.25 秒内消失；再次悬停后按 **Escape** → 立即消失。
5. **左键**点托盘 → 主窗口显示/隐藏正常、浮层不残留；**右键** → 原生菜单正常、各项行为不变。
6. 任务栏不在底部（或接了第二台显示器）时，把任务栏移到上方/左侧或在第二屏重复第 2 步 → 浮层应贴正确一侧、不出屏、不压光标。（本机因用户实例占用 WebView2 无法冒烟，故以上 6 步即本轮的验收方式。）

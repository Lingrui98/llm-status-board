# v0.2.14 — 自定义趋势跟随当前时间与 ModelServer 登录

## 自定义趋势范围

- 在「自定义」时间范围的结束时间旁新增「到现在」选项，固定开始时间并让结束时间随当前时间推进，后续采样自动纳入曲线。
- Codex 额度历史、账号余额、总额度及全局余额趋势均支持此选项。
- 取消勾选后恢复原先手动选择的结束时间；切换预设范围再返回自定义时保留选择。
- 改善时间输入框的明暗主题样式，窄面板自动上下排列；校验缺失或晚于当前时间的开始时间。

## ModelServer 登录

- 新增 ModelServer 网页登录获取凭据入口，可直接完成登录，无需手动从浏览器中提取刷新令牌。

## 验证

- 前端 616 项测试、TypeScript 与 Vite 生产构建通过。
- Rust 199 项单元测试、格式检查及所有目标的 Clippy 检查通过；7 项真实网络测试按原配置忽略。
- 实际桌面验证动态时间推进、手动结束时间恢复及明暗主题与窄面板布局。

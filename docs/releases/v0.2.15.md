# v0.2.15 — 托盘悬停提示修复

## 托盘悬停

- 移除托盘的原生系统提示框。悬停时只显示自绘的用量总结窗口，系统提示框不再遮挡总结内容。
- Windows 托盘改用 NOTIFYICON_VERSION_4 协议注册。仅当提示文案非空时才请求 NIF_SHOWTIP，因此不再出现空白系统提示框。
- 适配版本 4 回调：图标激活使用 NIN_SELECT / NIN_KEYSELECT，右键菜单使用 WM_CONTEXTMENU，并且不重复发出 button-up 事件。
- Explorer 重启后重新注册时重复版本协商。协商失败时保留旧协议的回调解释。

## 实现说明

- 通过 Cargo patch 引入 tray-icon 0.25.1 的本地补丁。补丁只修改 Windows 后端，保留原有公共 API 与其他平台实现。
- Windows 通知实现接受可注入的 Shell 调用。单元测试在三个平台执行真实的注册与回调代码。

## 验证

- 前端 616 项测试、TypeScript 与 Vite 生产构建通过。
- Rust 单元测试、格式检查与 Clippy（deny warnings）在 Windows 与 macOS CI 执行。
- Release 工作流生成并校验三平台安装包与更新签名清单。

## 安装与更新

Windows x64、macOS Apple Silicon 与 Intel 安装包见 Assets。已有 v0.2.4 及以上版本可在「设置 → 关于与更新」中通过稳定版渠道检查更新。

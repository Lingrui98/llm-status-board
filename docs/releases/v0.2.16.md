# v0.2.16 — macOS 托盘浮层缩放与焦点修复

## 托盘浮层

- 修复 macOS 右下角手柄无法调整浮层大小的问题。macOS 使用独立拖拽实现，Windows 保留原生缩放方式。
- 修复其他应用处于前台时，浮层手柄必须先点击才更新缩放光标的问题。较新 macOS 使用系统斜向缩放光标，不支持该接口的旧版 macOS 使用十字光标。
- macOS 浮层改为非激活面板。悬停和调整尺寸不再调用应用级激活接口，避免主窗口在拖动结束后跳到前台。
- 快速拖动时合并尺寸请求，保留尺寸限制，并在视口更新后保存尺寸。
- 减轻浮层阴影，避免底部阴影被透明窗口边界裁出硬线。

## 验证

- 前端 630 项测试通过，TypeScript 与 Vite 生产构建通过。
- macOS 浮层相关 20 项 Rust 测试通过。
- 用户在 Apple Silicon Mac 上确认：未点击时缩放光标正常变化，拖动后主窗口不抢前台，阴影更自然。
- Windows 与 macOS CI 执行 Rust 格式检查、Clippy 和单元测试。Release 工作流构建 Windows x64、macOS Apple Silicon 和 Intel 安装包。

## 安装与更新

Windows x64、macOS Apple Silicon 与 Intel 安装包见 Assets。已有 v0.2.4 及以上版本可在「设置 → 关于与更新」中通过稳定版渠道检查更新。

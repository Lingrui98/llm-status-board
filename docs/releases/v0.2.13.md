# v0.2.13 — 看板与主题优化、用量趋势修复

## 看板与设置

- 总览条升级为 KPI 卡片，增加今日消耗、账号状态和刷新信息。
- 四类全局图合并为 Tab 卡片，用量趋势支持 7、14、30 天范围。
- 账号卡片按内容收缩，增加品牌徽标、余额迷你趋势线和数字排版优化。
- 异常卡片降低视觉干扰，保留重试、编辑配置和上次成功信息。
- 设置页增加分区导航，账号编辑入口可直接定位到对应表单。

## 外观与主题

- 新增深色、浅色、跟随系统、固定时间、日出日落五种主题模式。
- 固定时间支持跨午夜，系统主题变化会立即生效。
- 日出日落模式支持自定义经纬度，并处理极昼、极夜和夏令时。
- 主窗口与托盘浮层共用主题设置，跨午夜后自动更新今日数据。

## 用量趋势修复

- 多账号趋势改为独立折线，提示框数值与纵坐标保持一致。
- 统一图表、今日费用、用量历史和报表的日期口径。
- 修复重复日期、单点空态、窗口内账号排名和提示框标题。
- 无有效数据或仅有停用账号快照时，不再显示空统计区。

## 验证

- 前端 602 项测试通过。
- TypeScript 与 Vite 生产构建通过。
- Rust 格式检查及 Windows / macOS 云端检查通过。三平台安装包与更新签名清单已验证。

## 安装与更新

Windows / macOS 安装包见 Assets。已有 v0.2.4 及以上版本可在软件内检查更新。

# Round 25 计划：悬停浮层「移过去就消失」修复（光标驻留保活）

## 0. 问题

用户反馈：鼠标移到托盘图标浮层弹出后，把鼠标移向浮层本身时浮层经常消失。预期：光标在浮层范围内时应保持不消失。

## 1. 定位

原链路（R18）：离开图标 → 250ms 后隐藏；进入浮层 → IPC 回报取消隐藏。链条脆弱点：
- 图标与浮层之间有 8px 间隔 + 浮层 6px 透明边距（透明窗口的 alpha=0 区域在 Windows 上不吃鼠标事件）；
- 移动稍慢或中途停顿超过 250ms → 隐藏定时器先触发，浮层在用户到达前消失。

## 2. 方案

隐藏定时器到点时**不直接隐藏**，先做「光标驻留」判定：

- 光标屏幕绝对位置 = 浮层 `outer_position()`（屏幕绝对）+ `cursor_position()`（客户区相对）；
- 光标落在「托盘图标 ∪ 浮层」任一矩形（各外扩 6px 余量，覆盖间隙与透明边距）→ 不隐藏，200ms 后复查；
- 复查链只存在于「该隐藏但光标仍在范围内」期间；光标真正离开后下一次复查即隐藏；
- 光标/窗口几何读不到 → 回退到原隐藏行为（宁可按时隐藏，不让浮层卡死）。

核心判定 `cursor_allows_stay` 为纯函数（屏幕绝对物理像素），覆盖：图标内/浮层内驻留、余量覆盖间隙、几何缺失回退。

## 3. 改动

- `summary.rs`：`cursor_allows_stay`（纯函数）+ `cursor_screen_position` / `cursor_allows_stay_now`（运行时读取）+ `PhysRect::inflated`；`schedule_timer` 的 HideNow 分支接入判定；常量 `KEEPALIVE_MARGIN_PX=6` / `KEEPALIVE_RECHECK_MS=200`。
- 新增 3 组单测（驻留命中/余量覆盖/缺失回退）。
- 版本 0.2.7 → 0.2.8。前端无改动。
